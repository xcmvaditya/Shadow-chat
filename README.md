# ShadowChat

Developed by Aditya

Termux terminal chat tool with AES-256 encryption, Firebase backend, multi-room support.

## Install
pkg install git -y
git clone https://github.com/YOUR-USERNAME/shadowchat
cd shadowchat
bash install.sh
python shadowchat.py

## Features
- AES-256 encrypted messages
- Multi-user login/register
- Multi-room + DMs
- File transfer
- Session resume
